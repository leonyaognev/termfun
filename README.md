## Особенности

- Классический Tetris с семью тетромино (`I, O, T, L, J, S, Z`).
- Движение, вращение, жёсткое падение и пауза.
- Отслеживание очков, уровня и рекорда.
- Терминальный интерфейс на `ncurses`.
- Модульная структура: логика игры, интерфейс, ядро и тесты отдельно.
- Полный набор тестов на `Check`.
- Генерация отчётов покрытия с помощью `lcov`/`genhtml`.
- Проверка памяти через `valgrind`.

---

## Требования

- **Компилятор C:** `gcc`
- **Библиотеки:** `ncurses`, `check`
- **Инструменты:** `make`, `lcov`, `genhtml`, `valgrind` (Linux) или `leaks` (macOS)
- Рекомендуется POSIX-совместимая среда (Linux/macOS)

## Диаграмма клеточного автомата
```mermaid
stateDiagram-v2
    [*] --> Start: запуск игры
    Start --> Spawn: создаём новую фигуру
    Spawn --> Falling: фигура падает
    Falling --> Lock: фигура приземлилась
    Falling --> Pause: ползователь остановил игру
    Pause --> Falling: пользователь возобновил игру
    Lock --> ClearCheck: проверка линий
    ClearCheck --> Clear: есть линии для очистки
    ClearCheck --> Spawn: линий нет, спавним новую фигуру
    Clear --> Spawn: очистили линии, спавним новую фигуру
    Spawn --> GameOver: нет места для новой фигуры
    GameOver --> Falling: ждём рестарт и возвращаемся к падению
```

## Сборка

Сборка всего проекта (библиотеки и исполняемый файл):

```bash
make all
````

Компилирует:

* Логику Tetris: `build/s21_tetris_logics_lib.a`
* Интерфейс TUI: `build/s21_tui_lib.a`
* Библиотеку для покрытия: `build/s21_tetris_logics_gcov.a`
* Устанавливает исполняемый файл `/usr/bin/tetris`.

Установка без ручной сборки:

```bash
make install
```

Удаление игры и кеша:

```bash
make uninstall
```

## Запуск игры

После установки:

```bash
tetris
```

Управление:

* **Стрелки:** движение и вращение
* **Вниз:** мягкое падение
* **Вверх:** вращение
* **Пробел/Action:** жёсткое падение
* **ESC:** пауза
* **Q:** выйти/завершить игру
* **Enter:** старт/перезапуск игры

## Тестирование

Запуск полного набора тестов:

```bash
make run_test
```

Проверяются инварианты, движения, вращения, жёсткое падение и сценарии.

## Покрытие кода

Генерация отчёта покрытия:

```bash
make gcov_report
```

Откройте в браузере:

```
build/coverage_html/index.html
```

---

## Проверка памяти

Проверка утечек и ошибок памяти:

```bash
make valgrind_test
```

* Используется `valgrind` на Linux.
* Используется `leaks` на macOS.
